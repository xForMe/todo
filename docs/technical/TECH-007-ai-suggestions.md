## 分层归属与确认新建（2026-11-14）

SRC-FEISHU-006：用户要求模块和事情分别选择，不存在时可新建，并希望 AI 自动识别。核对抽屉采用目标→模块→事情联动选择；聊天新事件可选择新建模块/事情，AI 可推荐已有 ID、新名称与理由，未知留空，不默认当前页面归属。用户一次确认后将模块、事情、事件整体保存，失败整体回滚，重复确认不重复创建。已有事件更新、文档上下文不得扩展范围；不自动新建目标，不按相似名称自动合并。

验收覆盖新建模块+事情+事件、已有模块下新事情、已有事情、无目标/父项缺失、跨账号、同名冲突、重复提交、失败回滚。使用新字段可选默认空以兼容历史建议；不批量改写旧建议。交互补充见 PRO-006。


实现：Proposal 增加可选 goal_id/module_id/new_module_name/new_thing_name/placement_reason，兼容旧 JSON；模型工作范围增加纯标题完整 path，不增加正文提交范围。服务端验证 ID 所有权、类型及层级，输出新名称只落建议表。确认请求可带 placement，已有事件更新及文档不允许该参数。聊天新事件确认以建议 ID 幂等，单事务创建可选层级和事件、更新 accepted/event_id 回执，再读回事件；失败回滚。模块/事情同父项精确同名拒绝，要求用户选择已有项。旧 accepted/applying 记录保持兼容。新建节点用 ItemInput 统一字段校验；不扩展外部发送。
