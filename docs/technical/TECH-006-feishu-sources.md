用户确认原型并授权开发。首片实现来源持久化、上下文授权、读取适配及右侧抽屉。沿用个人本机会话。文档只能挂事情/事件，聊天独立于目标和模块，服务端校验所有者与类型。客户端生成来源 UUID 作为创建幂等键，编辑按版本比较；写后读回，来源删除采用停用标记。

新增独立 source_records 表；迁移只新增表，普通启动不迁移，执行迁移前备份已有 SQLite。来源保存 URL/聊天 ID、周期、版本、启用状态、最后读取结果和时间。文档去除查询与片段，只允许飞书/Lark wiki/docx 路径；原始正文只展示为文本。

原生 CLI 可执行文件来自本地 npm 包 bin 或 TODO_FEISHU_CLI_EXE，固定只读命令参数列表、shell=False、user 身份；超时与大小上限，错误不暴露原始响应。每轮群聊读取最新最多 20 条，明确标记部分结果，不宣称完整增量采集。文档读取当前版本。读取不改变正式事件。

应用存活期间后台任务扫描持久化来源，到期先原子领取时间窗口，再读取；结果写入必须匹配来源版本和启用状态，暂停后丢弃在途结果。失败暂停，手动恢复。此片不提供可靠外部发送调度，不产生任何外部写入。AI 未配置明确显示，不生成样例建议。模型接入及催办为后续独立切片，不能把本片当作全量完成。

## 聊天独立来源修订（2026-11-14）

SRC-FEISHU-005：用户明确确认聊天来源不绑定目标或模块。AI 在当前账号全部目标、模块、事情和事件中判断归属，歧义进入待确认，不回退当前模块。文档仍限定原有事情/事件上下文。旧聊天配置解除绑定并暂停，保留所有业务记录与建议；同账号同群只能启用一条读取配置。确认新建议可选择账号内任意事情，界面展示目标/模块/事情完整路径。既有已确认结果不自动移动。

## 前端旧版本修复（2026-11-14）

来源 SRC-FEISHU-005 的用户截图反馈：旧页面仍按模块过滤，造成全局来源不可见。源码已解绑但 sources.js/suggestions.js 引用版本未更新。提升引用版本，并让本机静态文件响应不缓存、忽略旧条件请求，避免 HTML 与脚本版本混用。本次不改来源记录、启停状态或权限。对应 TEST-005 回归。
