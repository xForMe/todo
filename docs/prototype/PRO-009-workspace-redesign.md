左侧常驻导航提供工作台、目标与事情、来源设置；手机收为顶部紧凑导航。首页为标题/范围→目标概览条目→行动清单与右侧关注、评估。目标与事情保留目标/模块选择、左事情右事件结构。详情、编辑、来源均保留右侧抽屉。

SRC-UI-006：聊天来源抽屉标题后直接展示群聊会话ID与读取周期，不展示AI归属说明和供应商/型号提示段。授权勾选仍在表单中，云文档来源仅展示实际所属对象。

HTML 使用独立示例数据，覆盖导航、筛选、详情、空态及错误状态，仅用于结构核对，不写真实记录。实现前静态核对入口和异常状态；遵循原型直接交付约定，不启动原型服务。正式应用另行进行浏览器验证。

SRC-UI-005：依7条浏览器批注精简页面。标题下无口号，目标概览仅标题；日期不附时区。评估区保留筛选与状态，去掉说明段；新增目标/模块为不可拆分的一组，手机也相邻。优先级为可点击标签外观，保留评估抽屉和键盘操作；事件完成控件与标题首行对齐。空态只说明当前无数据，真实说明为空时不补写引导文案。原型同步删除口号和计数说明，正式应用验证见TEST-011补充记录。
