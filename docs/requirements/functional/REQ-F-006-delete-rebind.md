# REQ-F-006 删除与下级换绑

**类型**：功能需求
**状态**：review
**负责人**：待指定
**更新时间**：2026-11-14
**source_architecture**：PA-001 §3、§4.2
**关联文档**：REQ-F-006、PRO-004、TECH-009、TEST-006

来源 SRC-DELETE-001：2026-11-14 用户要求目标/模块/事情提供删除，有内容时支持换绑。
范围：空对象确认删除；有下级内容、云文档或待确认建议时，先选择当前账号的另一个同类对象接收全部内容，再删除。接收位置可跨目标/模块，展示完整路径。保留事件状态、责任人、时间、原文和历史催办记录；受影响来源及催办暂停供用户核对。
验收：删除对象从工作列表及 AI 上下文消失；子树完整保留并显示在接收位置；无接收位置时提示先创建；禁止自身、错类型、其他账号、已删除对象作为接收位置。下级或关联内容变化后须刷新确认。未知结果可核对，同操作不重复执行。
不做：连带删除下级、事件删除、逐条分配多个接收位置、回收站恢复界面、外部消息发送。删除保留内部历史供审计。


## 同名模块融合（2026-11-14）

SRC-DELETE-002：用户明确确认“同名模块合成一个，内容合在一起”。目标换绑时，对接收目标下与转入模块名称完全相同的模块合并，优先保留接收方模块身份；事情和事件追加保留，不按同名自动去重。不同模块名称不猜测合并。模块双方说明均保留，超出说明长度上限则拒绝并回滚。既有两条“智能输配”模块经本次授权合并。前端确认文案说明同名模块融合，仍沿用右侧抽屉。
