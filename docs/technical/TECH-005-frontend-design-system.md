## 强制流程

1. frontend-design：实现前明确用途、布局、视觉方向和交互状态。遵循已确认原型，不靠生成图片代替可实现规范。
2. design-system：基础值→语义→组件三层 CSS token。颜色、间距、字号、圆角集中在 tokens.css；组件引用变量。图标统一为单色线性 SVG，禁止文字符号拼装图标。
3. design-review：检查实际运行页面及截图，覆盖 1440、1024、768、375 宽度、空态、有数据、长文本、弹窗、错误反馈和键盘焦点；修正发现项后复查。功能测试不得代替视觉检查。工具辅助脚本不可用时采用其检查清单与现有浏览器，报告降级边界。

## 本片设计基线

深蓝冷灰底色，青色仅用于主要动作和选中状态；正文高对比，辅助文字不低于可读对比。4px 间距阶梯，正文 14–16px、标题 24–28px。表格可内部滚动，页面不可横溢；手机采用纵向布局。hover、pressed、focus-visible、disabled 明确；状态同时有文字。动画尊重 reduced-motion。使用本机中文字体避免外部字体请求。设计方向采用用户确认；提交前记录真实截图与剩余限制。
