## 页面与旅程

依据用户认可的视觉方向 PRO-001-tech-visual-v2.png，采用深蓝与青色科技风。顶部全局导航，下方目标与模块选择栏，内容区左侧事情卡片、右侧事情详情与事件表格；窄屏纵向排列。未进入本切片的顶部导航禁用并标记为后续规划。页面明确标记示例与原型身份。

1. 新建目标，然后在目标下新建模块。
2. 选择模块，新建事情；选中事情后新建事件。
3. 通过各层级的编辑入口修改名称及说明。
4. 点击事件圆圈完成，再次点击撤销；所属事情不自动完成。
5. 重新打开同一浏览器地址，查看本地保存的内容。

## 状态及异常展示

- 无数据时显示首次创建提示；未选择模块时禁用新建事情。
- 空名称保留表单并显示校验信息。
- 原型评审工具可模拟无权限、父项失效、冲突、保存失败、结果不确定；异常保留输入并且不显示成功。
- 模拟结果不确定不会实际写入；真实写入后读回失败的恢复机制留待技术阶段。
- 恢复示例或切换空白空间需要确认，且只替换原型数据。
- 所有内容仅在当前浏览器本地保存，不接入账号、业务数据库、飞书或模型。不同浏览器及不同地址的数据不互通。
