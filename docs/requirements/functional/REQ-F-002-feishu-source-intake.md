## 来源与场景

SRC-FEISHU-001：2026-11-13 本次用户讨论，明确通过飞书 CLI 获取聊天记录、读取云文档进行识别；催办发责任人私聊；要求验证与业务代码隔离，并在验证后要求开始。CLI 是用户指定的接入约束，具体实现另记技术方案。

用户在推进一件事情时，把指定聊天的一段讨论或云文档作为工作依据，减少复制整理，保留回看原文的能力。本项先提供可独立验收的来源读取与关联，是下一项 AI 识别的输入。

## 范围及操作

1. 用户在设置中配置聊天、首次回溯范围、允许匹配范围与同步频率。云文档在具体事情或事件中关联，明确授权后自动读取识别；事件入口保留上下文，新行动归入事件所属事情。
2. 启用后后台持续读取新增或变更内容，自动交由 AI 识别；展示最近同步、失败、分页或截断状态，不要求逐轮手动触发。
3. 聊天保留消息标识、发送人、时间及原消息入口；文档保留标题、文档标识、版本信息（来源提供时）及干净链接。
4. 同一来源再次读取不重复创建关联；来源更新不得直接覆盖本地事件及其状态。
5. 只读取用户指定范围，不默认扫描全部聊天、通讯录和云空间；只在已授权来源范围内后台持续采集。
6. 用户可暂停、恢复或移除来源；暂停及移除停止后续读取和识别，已有事件与进展保留，不删除飞书源内容。来源保存范围和保留期限需在需求评审时确定。

## 异常路径

- 身份或授权失效、资源不可见时给出具体提示，不把错误显示为空列表。
- 空结果、部分结果、完整结果明确区分；页数或条数达到限制时标明未读完。
- 不保存分享链接中的临时登录凭据，不显示密钥。
- 关联前检查事情的权限、范围和当前状态；保存后读回。失败或结果未知时不提示成功，不静默重试写入。
- 来源被删除或撤权后标明不可访问，不将旧快照伪装为最新内容。

## 验收条件

| 编号 | 可观察结果 |
|---|---|
| AC-01 | 指定聊天和时间范围后能看到返回消息及可追溯来源，空结果有明确提示。 |
| AC-02 | 指定云文档后能看到正文与表格内容，不能访问时明确报错。 |
| AC-03 | 首次明确授权后自动同步并关联到已配置范围，重复读取不产生重复记录，暂停后停止。 |
| AC-04 | 分页截断、授权失效、来源不可用均可区分，未知结果不冒充成功。 |
| AC-05 | 原有本地数据不被清空，源链接中的临时凭据不进入保存结果。 |

## 不做与待确认

不做消息发送、AI 调用、飞书任务同步、附件下载、全量历史抓取和自动事件创建。建议每轮分批读取最多 20 条并受限续取，未读完显示部分结果；此上限、来源快照保留期限及私聊联系人选择方式待确认。样例验证不能替代正式功能验收。
