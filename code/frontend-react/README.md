# 前端

## React 正式入口

React 接管全局导航、工作空间栏、共用图标提示与全局状态反馈、工作台主区，以及「目标与事情」两侧面板：面包屑与选择、事情列表与筛选、当前事情、事件表和来源进展。通用新建和编辑表单（含摘要、模块记忆、迁移和删除入口）也由 React 渲染，保留原生模态外壳与业务控制；通用保存待核对与连接入口、工作台详情与关注核对、事件详情（含标题、图片入口和操作核对）、拆分、后续跟进、前置编辑与等待原因、延期变更与历史、当日跟进、事情优先级/每周评估、事件归属迁移、删除/换绑、来源管理、自动催办、事件识别、建议核对、图片管理、事情智能拆解、当前工作摘要、模块记忆和记忆候选的浮层内容（含建议中的记忆引用）也由 React 渲染，编辑和跟进里的附件控件、设置外壳、分类导航与数据渠道入口，以及图片存储、大模型和提示词配置同样如此。保留原生模态外壳与业务控制器。正式启动会先构建前端（需 Node.js 22.12+ 和 npm）。只构建前端、不重启服务时，在项目根目录执行：

```powershell
& .\code\scripts\build-frontend.ps1
# 依赖已安装时只构建
& .\code\scripts\build-frontend.ps1 -SkipSync
```

前端只使用本目录：`src/` 保存 React 源码，`public/` 保存 HTML、业务控制器和样式，`public/dist/` 保存构建产物。FastAPI 仅托管 `public/`，不托管工程根目录。旧链接的 `ui` 参数不再切换实现；缺少或不兼容的产物时，页面仅显示构建提示，不开放业务操作。无需 Vite 服务或数据库迁移；React 源码及 npm 依赖不放入托管目录。从项目根执行 `npm --prefix code/frontend-react test` 做主流程回归，或加用 `npm --prefix code/frontend-react run test:acceptance` 同时跑抽屉、跟进、图片、设置、记忆等专项。需要本机 Chrome；这些脚本拦截请求，不运行要求真实服务的旧脚本。

2026-11-14 视觉重构（历史基线）：REQ-O-003 / PRO-009 / TECH-014 / TEST-011。当前 React 继续复用 `tokens.css` 的语义变量、`style.css` 的骨架与共用组件、`workbench.css` 的首页样式。旧视觉版保存在 `archive/frontend/REQ-O-003-before`。CSS 自适应覆盖桌面侧栏、平板顶部导航和手机单列；事件表仅内部滚动。

工作数据的源需求是 REQ-F-001，原型 PRO-001，技术 TECH-004。`public/index.html` 提供启动页和原生宿主，`public/app.js` 等脚本保留业务控制，React 组件源码在 `src/` 内。请按 [启动说明](../README.md#一键启动) 运行；直接打开 HTML 文件不能调用同源接口。业务数据只存数据库，不导入原型 localStorage 数据。

事件迁移由 `event-move.js` 实现（REQ-F-011 / TECH-015），复用抽屉、token 与图标；入口在事件详情和编辑中。目标联动选择、影响预览、确认写入、刷新后恢复均由独立迁移端点和回执处理。
