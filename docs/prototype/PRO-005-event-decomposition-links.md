## 页面与交互

沿用目标/模块—事情—事件结构，深蓝青色视觉和右侧抽屉。提供多级拆分、新建独立事件、事件状态更新、同事情关联、独立跟进、移除关联、空态及计数变化。详情显示父级与关联事件，树形列表展示子级进展和父事件待确认提示。

最末级未取消事件计数；包含未拆分事件，不重复计算父事件。初始示例为完成 2/有效 3，取消 1，显示 67%。完成核对清单后为 100%，父事件仍进行中。

未结束后代阻止完成或取消父事件。已完成/取消祖先阻止新增或重开子事件，提示先显式重开。取消、所有子级取消时允许手动完成等规则均为评审建议。通过底部演示选择器展示保存失败、状态过期、结果未知后核对；均为页面内模拟。

## 评审步骤

1. 尝试直接完成准备评审，查看子事件拦截。
2. 完成核对清单，观察 100% 与父事件待确认并存，再手动完成父事件。
3. 从叶子事件继续拆分，观察分母和进度变化；完成状态下先手动重开。
4. 对历史已完成事件新建后续跟进，检查历史状态保持。
5. 关联已有事件并移除关系，检查事件仍保留。
6. 切换资料归档查看空态；切换失败模式查看错误反馈。
